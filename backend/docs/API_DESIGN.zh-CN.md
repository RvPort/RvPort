# 后端当前接口索引

[English](API_DESIGN.md) | 简体中文

本索引按当前控制器路由整理，包含 JSON、下载和 SSE 入口。请求与响应以对应 DTO 和控制器单元测试为准；认证和权限以安全配置与业务访问检查为准。产品的自动化测试、环境连接测试和模型测试均为正式能力。

本索引包含 171 个路由，其中 3 个 SSE 入口。

项目 overview 的主线推荐、报告复核摘要及旧前端覆盖逻辑的对接要求见 [工作流主线推荐契约](工作流主线推荐契约.md)。推荐为导航焦点，阶段执行资格仍由各自 readiness 决定。
